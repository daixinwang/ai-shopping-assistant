## 三、核心功能实现详情

### 3.1 拍照识物模块

**服务端：** `backend/services/vision_service.py`
- 调用AI视觉模型识别商品
- 返回结构化识别结果（类目、品牌、颜色、风格、特征、关键词）
- 支持重试机制和降级处理

**客户端：** `mobile/src/screens/CameraScreen.tsx`
- 支持相机拍摄和相册选择
- 图片上传与识别状态管理
- 识别完成后跳转结果页

### 3.2 智能建议卡片模块

**服务端：** `backend/services/suggestion_service.py`
- 根据识别结果动态生成4-5个建议卡片
- 每个卡片携带筛选参数
- 支持默认卡片降级

**客户端：** `mobile/src/screens/RecognitionScreen.tsx`
- 横向滚动展示建议卡片
- 点击卡片触发商品筛选

### 3.3 自然语言筛选模块

**服务端：** `backend/services/intent_service.py`
- 解析自然语言为结构化过滤条件
- 支持价格区间、颜色、评分、平台、店铺类型等

**客户端：** `mobile/src/components/NLFilterBar.tsx`
- 输入框输入自然语言
- 实时展示已应用的筛选标签

### 3.4 商品数据

**数据源：** `backend/data/mock_products.json`
- 覆盖5大类目：运动鞋、手机、耳机、T恤、包包
- 包含多平台价格、评分、销量等信息
