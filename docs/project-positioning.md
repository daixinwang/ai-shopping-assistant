# 项目定位

AI 购物助手展示的是垂直业务 Agent，而不是电商爬虫或通用聊天壳。它把多模态输入、约束理解、目录检索、会话状态、工具调用和移动端操作串成一个可测试闭环。

## 与 Eino-Researcher 的互补

| 项目 | 重点 | 主要证据 |
|---|---|---|
| Eino-Researcher | 研究型 RAG 基础设施与检索可靠性 | Go、Eino、PostgreSQL/pgvector、文档上传切片、Embedding、HNSW、引用回答 |
| AI 购物助手 | 面向业务动作的多模态有状态 Agent | 图文输入、工具路由、多轮 refine、SQLite 商品事实、对比/购物车/偏好、React Native |

两个项目共同体现检索、状态、错误处理、可观测性和测试，但不重复讲同一个故事。本项目的合理简历表述是“基于固定演示目录完成购物决策前闭环”，不能描述成“已接入全网实时价格”或“线上生产商城”。

## 可演示亮点

1. 在没有任何模型 Key 时运行完整自动测试和 lexical 检索。
2. 用 Fake Adapter 稳定复现超时、429、5xx、非法 JSON 和流式中断。
3. 同一会话中追加预算、品牌和排除条件，展示状态化 refine。
4. 图片经过安全校验后进入与文本相同的推荐链路。
5. 前端把 Agent 工具结果渲染为可操作商品卡，而不是只显示聊天文本。

## 明确未完成

真实平台采集、跨平台 SKU 对齐、库存/价格监控、支付、用户认证、多租户隔离和生产部署均不在本轮范围。Hybrid 与真实豆包调用需要使用者自己的有效配置，自动测试不访问外网。
